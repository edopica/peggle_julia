## Decisions & Learnings
- **Reference is committed `d17f6e7`, not the working tree.** The Lua tree had
  uncommitted edits in `path.lua` and `physics.lua`; a reference must be
  reconstructible from a commit, so they are excluded. If committed later, the
  pin advances and all baselines and fixtures are re-captured.
- **The action space is 1801 aim indices, not 1800.** The grid comes from the
  snapping function (`floor(n*1800 + 0.5)/1800`), which reaches index 1800 at
  the arc endpoint. The harness proves `getSnappedAimAngle(angle(i)) ==
  angle(i)` for all indices before every run.
- **Default shot end is the bench boundary** (no launched ball remains),
  keeping M0 comparable with existing Lua tools. `--clearing on` measures
  through end-of-turn clearing to the next ready-to-aim boundary; that is the
  M4 completion rule.
- **Per-candidate `init` dominates dense levels.** On `annular_dense`,
  rebuilding the level (including regenerating 192 annular pegs) costs 81 ms
  at p50 against 5.5 ms of simulation. The M2 checkpoint contract removes
  this cost: about 15x potential throughput on that workload. This is the
  strongest measured justification for the checkpoint/reset design.
- **Simulation cost is long-tailed.** On `lines_rect_annular`, `sim` p50 is
  2.8 ms but p90 is 22.5 ms. Median-only reporting would hide the cost of
  slide-heavy shots.
- **The baseline host throttles under sustained load.** Repeats 1 to 3 slowed
  from 11.2 to 7.5 candidates/s on `annular_dense`, with the CPU at 94.5 C
  while the desktop session also ran. Determinism spot checks passed in every
  workload, so this is thermal/contention variance, not engine
  nondeterminism. Dedicated benchmark hardware remains deferred, per plan.
- **Replay serialization stays in the baseline.** `launchBalls` serializes
  the rolling capture in the real game; removing it silently would credit the
  port for less work. `--no-replay-serialize` exists for experiments only.
- **Documentation now lives under `wiki/`**, matching the parent repository,
  with `tmp/` (or the parent `temp/`) reserved for ephemeral notes.

## Verification
- `make verify`: 133 files match `reference/files.sha256`; a fresh clone also
  verifies clean.
- `make test`: 475 passed, 0 failed on the pinned reference (run in a scratch
  copy because the test suite writes to `temp/`).
- `make self-check`: grid identity OK (0 mismatches); candidate determinism
  0 mismatches across all seven workloads.
- Baseline run `20261003T093826Z`: 37,821 candidates, 37,821 completed,
  0 incomplete, 1570 s, 24.1 candidates/s. Summary:
  `results/20261003T093826Z_omarchy.summary.json`; analysis:
  `wiki/benchmarks/baseline-metrics.md`.
- Memory over the campaign: Lua heap 0.7 to 6.3 MiB, RSS 121.6 to 142.0 MiB,
  confirming unbounded per-candidate allocation ahead of the M4 target.
