## Decisions & Learnings
- **Trace backend identity is scope metadata.** The Julia trace header writes
  `math_backend` only when the DetMath backend is not `system_libm`
  (`DetMath.math_backend_identity()`). `tools/compare_traces.py` records the
  block and never counts it as a simulation difference. Default `system_libm`
  traces stay byte-identical between Lua and Julia.
- **The benchmark needs its own workload catalog.** The pinned
  `harness/workloads.lua` cannot load the untracked mustache level. The
  additive `--workloads FILE` option and `fixtures/mustache/workloads.lua`
  keep the pinned catalog and the M0/M1 sweeps unchanged. `--artifact-dir`
  does the same for the level artifact.
- **Spawn coverage lives in the traces.** The Lua raw sweep format does not
  emit `spawned`, so the sweep comparison covers 16 shared fields. The
  multiball trace fixture covers spawn behavior instead.
- **Snapshots are comparison artifacts.** The durable corpus stays
  snapshot-free to bound repository size. The comparator still requires full
  per-step snapshot coverage on both sides.
- **Speedup claims stay caveated.** The 1.95x same-core figure compares one
  post-warmup Julia pass with a Lua repeat=2 mean. Rates vary between runs,
  so the report labels the ratio indicative.
