## Saving Plans and Documentation

Always save all plans, reports, decisions, and documentation in the `temp/` directory
at the project root. This directory is gitignored and exists for ephemeral planning
work. Do not use editor-specific directories (e.g., `.opencode/`, `<appDataDir>/brain/`)
to store plans or user-facing reports.
