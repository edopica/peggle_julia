# Dev Log - 2026-09-02

## Progress Summary
- Completed the peg motion ownership refactor (ADR-0007): `level_data.pegs`
  is now the only peg collection, `peg.motion` is the only moving-peg
  assignment, `level_circuits` are immutable and peg-free, and `Circuits`
  is split into `initialize`/`update`.
- Migrated `level1` and `benchmark_lasagna` to the new schema with peg
  order/phase verified against a baseline capture.
- Removed the legacy grid benchmark levels (100/200/300/500/1000) and
  `test_rotation` (phase 6b was discarded by decision).

## Changes Made
- Added `src/systems/motion_schema.lua`: deterministic load-time motion
  validation (circuit-owned pegs, legacy fields, unknown references,
  malformed primitives, timed-circuit pause policy; one-time `path_fn`
  warnings).
- Split `src/systems/circuits.lua` into `Circuits.initialize()` /
  `Circuits.update()` with secant-velocity contract and timer-overshoot
  preservation across move/pause boundaries.
- Fixed annular geometry in `src/entities/peg.lua`:
  `Peg.set_transform` rebuilds from base geometry whenever the applied
  rotation changes (including returning to zero); translation-only updates
  move in place.
- Reworked `Engine:setupLevel()`: single peg collection, schema validation,
  base-position validation before motion init, warning-only
  initialized-position check (`Validator.check_initialized_positions`).
- Replay format bumped to `schema_version = 2`: per-peg base transform,
  current transform, velocities, `hit_order`, and full runtime motion
  state; `base_angle` is now always the declared base. Legacy captures
  load through a compatibility adapter (level circuit assignment +
  `eval(circuit_t)`); replay runs are one-shot and terminate by
  themselves.
- `simulation_snapshot.lua` keeps flat trace-compatibility fields derived
  from `peg.motion` and adds the authoritative `motion` sub-table
  (snapshot `schema_version = 2`).
- Updated tools (`level_checker`, `circuit_analyzer`, `overlap_detector`,
  `impact_debug`, `tools/check_level.lua`) to the motion model.

## Verification

## Review Fix Round

### Progress Summary
- A review round over the ADR-0007 motion/replay work fixed replay state
  fidelity gaps (scoring progress, bucket exactness, ball-ID serialization),
  a motion-time double-count in `Circuits`, double rotation on legacy
  rotating-annular restores, non-atomic replay schema validation,
  permissive motion-schema definitions, and `export_trace` level-setup
  parity. Cleanup covered wiki corrections and repo-hygiene items.
- Test suite grew from 232 to 262 (13 files; `test_level_manager.lua`
  added). Each fix landed with a test that fails on the pre-fix code.

### Changes Made
- `Circuits.advance_motion` consumes `dt` in a loop: path time advances
  only during moving portions, move/pause overshoot is never counted
  twice, and single steps can cross several move/pause boundaries.
- Replays (`schema_version = 2`) now capture and restore
  `redPegsHitAmount` and `currentMultiplier`; restore re-derives the
  multiplier via `updateMultiplier()` so `isFever` and fever-bucket
  activation are always consistent. Bucket state captures `phase` (full
  precision) and `x`, restoring `prev_x = x` to avoid a first-frame jump.
  Ball IDs serialize through the exact `%.17g` formatter (2⁵³−1 round-
  trips verbatim; `nil` ids still auto-allocate).
- `Replay.validate()` runs as the first statement of
  `Engine:applyReplayState`, before any mutation: only the legacy format
  (no version) or the exact integer `schema_version = 2` are accepted,
  with structural type-checks over every field the restore path reads.
- Legacy rotating-annular captures no longer double-apply rotation: the
  base-angle overwrite is gated to schema 2, so the adapter uses the
  level's declared base rotation plus `eval(circuit_t)`.
- `MotionSchema.validate` rejects `kind`+`path_fn` mixes, non-function
  `path_fn`, non-finite `frequency`/`angle`/`speed_angular`, non-boolean
  `rotate`, and all four legacy flat peg fields (`circuit_state` /
  `circuit_timer` included).
- `tools/export_trace.lua` now loads levels through `LevelManager` (per-
  level dimensions, e.g. level1 880×550), runs the full `setupLevel`
  validation order, and launches balls with the game's angle convention;
  the `--sweep` arc was re-centered around straight-down to match.
- `LevelManager` reports missing/deleted levels with a clean error;
  bench mode exits nonzero instead of crashing on a raw `require` miss.
- Wiki: corrected fever/circuit claims (circuits run every step, not
  just during fever), updated the Peg class diagram, quickstart test
  counts, and replay/schema references; `discuss.md` moved to `temp/`.
